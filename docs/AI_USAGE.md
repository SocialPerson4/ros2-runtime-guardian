# AI-assisted development disclosure

## AI参与范围

本仓库 `v0.1` 使用 OpenAI Codex 辅助完成：

- 初始目录和模块划分；
- Python代码初稿；
- 单元测试与GitHub Actions初稿；
- README、复现边界和路线图整理。

AI不是本项目运行时的一部分。程序不会调用大语言模型，也不会把本机运行数据发送到AI服务。

## 人工决策与当前状态

项目所有者确定了以下方向：以OS软件为重点，不涉及机械结构；采用“开源思路复现＋少量工程改进”的定位；公开说明AI参与；禁止把模拟回放写成真机结果。

截至 `v0.1`，自动化测试已经运行，但项目所有者仍需完成逐模块阅读、Linux环境复现和自主修改。完成这些工作前，本项目只能描述为“正在实现/学习复现”，不应写成个人独立完成的成熟系统。

## 使用AI后的责任边界

提交者对进入主分支的代码和陈述承担责任。合并后续修改前至少需要：

1. 能解释输入、输出和失败边界；
2. 亲自运行测试并保存日志；
3. 检查代码不包含密钥和隐私数据；
4. 明确区分模拟轨迹、CI证据和真机测量；
5. 对无法解释的AI建议不作成果声明。
