\datedsubsection{\textbf{Linux进程观测与ROS 2故障关联规则原型}\hfill\textbf{个人复现（进行中）}}{2026.09 - 至今}

\begin{itemize}[parsep=0.5ex]
  \item \textbf{项目背景：}面向机器人主机中节点异常与Linux资源状态分散的问题，复现ROS 2 diagnostics的分级诊断思想，先实现可独立验证的OS侧观测与规则基线。

  \item \textbf{核心工作：}基于Python读取Linux \texttt{/proc}，通过两次采样计算进程CPU，并采集RSS、线程、文件描述符及启动时间；以调用方提供的心跳年龄关联进程存活和CPU压力，设计带冷却时间、次数预算的dry-run恢复决策。

  \item \textbf{当前进展：}完成确定性JSONL回放、轻量Docker环境和GitHub Actions，\textbf{15项单元测试通过}；\texttt{rclpy}在线适配、节点到PID注册及树莓派ROS 2实验仍在实现，暂不报告真机性能。
\end{itemize}
